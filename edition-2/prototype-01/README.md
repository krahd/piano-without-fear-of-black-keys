**Status:** second-edition experiment; original v1.3 release remains untouched on main.  
**Audience:** experienced musicians who can play by shape, especially guitarists; not absolute beginners.

## Editorial proposition

*Piano Without Fear of Black Keys* is about the relationship between musical structures and the physical layouts through which musicians learn them. Guitar and keyboard make different relations accessible. A movable guitar grip can preserve fingering during transposition while every sounding note shifts; piano uses a fixed pitch map but changes the topography of an interval structure from key to key. The learner moves among chord identity, named pitches, sounding register, instrumental location and aural character, without treating any one of these as the musical object.

The revised book should begin with what musicians can already play, not with an inventory of elementary definitions. Detailed terminology follows a musical comparison that needs it. Modes are taught first through controlled changes in a stable tonic context, then through transposition and relationship to parent scales.

## Visual grammar to test

- **Paper:** warm off-white. **Ink:** near-black. **Root/tonic:** copper. **Other selected chord tones:** deep teal. **Altered degree:** paired copper and teal with explicit pitch labels. Never rely on colour alone.
- One consistent scale for note names, pitch classes, degree labels, octave indications and selected pitches; these are different information classes and must not be blurred by the diagram.
- Keyboard diagrams represent fixed sounding pitches and mark all selected keys. Guitar diagrams name string/fret and sounding pitches.
- Use paired examples: Dm/E♭m geometry, D Aeolian/D Dorian altered sixth, F♯ Aeolian/F♯ Dorian transfer.
- Avoid ornamental graphics and reference tables that do not serve an immediate musical operation.
- The publication must work in print without audio, but the chapter requires a linked set of original recorded examples before final publication.
- Prefer accessible serif/sans combinations, readable small-text sizes, live SVG diagrams and reliable PDF page breaking. All links must be canonical and untracked.

## Pedagogical test

A target reader should, without coaching:

1. Derive D–F–A from a familiar Dm grip, while distinguishing chord tones from D3–A3–D4–F4 (open guitar voicing).
2. Explain how a movable guitar grip and a piano triad embody the same intervals differently.
3. Hear B♭ versus B against a sustained D-minor reference, then explain the Aeolian/Dorian distinction.
4. Generate the analogous F♯-minor comparison, including D versus D♯, without memorising a keyboard diagram.
5. Recognise that the same pitch collection with a different tonic does not automatically produce the same mode.

The exercise is only successful if the reader can transfer the *relationship*, not merely repeat the example.
